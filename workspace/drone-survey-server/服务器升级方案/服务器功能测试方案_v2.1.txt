六、常见问题
=====================================================================

Q: 端口 9000 被占用?
A: 启动检查 [FAIL] 通信端口。关闭占用程序后重试。

Q: Exception ignored while closing generator?
A: Windows Python 3.14 asyncio 已知提示, 不影响功能。

Q: REST API 返回 auth required?
A: 浏览器登录页点"登录"获取 Token, 或用 curl 登录。

Q: WebSocket 连接失败?
A: 检查 6→13 是否启动。重启后 ws_test.py 测试。

Q: pyserial 找不到?
A: pip install pyserial
