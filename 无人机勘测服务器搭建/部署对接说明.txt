二、软件端 - 安装步骤 (在开发板上执行)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【硬件准备】
  1. 树莓派 (Raspberry Pi 3/4/5) + SD卡 (16G以上)
  2. K803 GNSS 模块 + 杜邦线
  3. 连接到同一 WiFi 网络

【接线 (K803 ←→ 树莓派 GPIO)】
  K803 VCC (3.3V) → 树莓派 Pin 1 (3.3V)
  K803 GND        → 树莓派 Pin 6 (GND)
  K803 TXD (输出)  → 树莓派 Pin 10 (GPIO15 / RXD)

【步骤1: 烧录系统到SD卡】
  (在PC上操作)
  1. 下载 Raspberry Pi Imager
     https://www.raspberrypi.com/software/
  2. 插入SD卡 → 打开Imager → 选择:
     - Raspberry Pi OS Lite (64-bit)
     - 选择SD卡
  3. 点击齿轮图标, 设置:
     主机名: survey-device
     启用SSH
     用户名: pi, 密码: raspberry
     WiFi: 你的WiFi名 + 密码
     地区: Asia/Shanghai
  4. 写入SD卡 → 插入树莓派 → 通电

【步骤2: 传输软件端代码到开发板】
  方法A: SCP网络传输 (PC上执行)
    scp -r E:\AI_Projects\Codex\无人机勘测服务器搭建\软件端 pi@survey-device.local:/home/pi/

  方法B: USB拷贝
    (PC) 复制 软件端/ 到U盘
    (树莓派) sudo cp -r /media/pi/U盘名/软件端 /home/pi/

  方法C: 使用部署脚本
    powershell -File 服务器端/deploy/pc_to_board.ps1
    输入板子IP, 自动传输

【步骤3: SSH登录开发板】
  查找板子IP:
    ping survey-device.local
  或查看路由器DHCP客户端列表

  SSH登录:
    ssh pi@survey-device.local

【步骤4: 安装依赖】
  cd /home/pi/软件端
  sudo apt update
  sudo apt install -y python3-pip
  pip3 install -r requirements.txt

【步骤5: 配置参数】
  cp .env.example .env
  nano .env
  
  填写以下内容:
  ┌─────────────────────────────────────┐
  │ DEVICE_ID=HW2024001    ← 设备编号   │
  │ MQTT_HOST=192.168.1.100 ← PC的IP    │
  │ MQTT_PORT=1883        ← MQTT端口    │
  │ MQTT_USER=            ← 留空(无加密) │
  │ MQTT_PASS=            ← 留空        │
  │ GPS_PORT=/dev/ttyAMA0 ← K803串口    │
  │ GPS_BAUD=9600         ← 波特率      │
  │ SURVEY_INTERVAL=60    ← 勘测间隔(秒)│
  └─────────────────────────────────────┘

【步骤6: 验证GPS模块】
  sudo apt install minicom
  minicom -D /dev/ttyAMA0 -b 9600
  应看到 $GPGGA, $GPRMC 等NMEA句子每秒刷新

【步骤7: 启动软件端】
  python3 main.py
  
  正常输出:
  ┌─────────────────────────────────┐
  │ Survey #1 - reading GPS...      │
  │   A: lat=30.25 lng=120.16 qual=1│
  │   B: lat=30.25 lng=120.16 qual=1│
  │   C: lat=30.25 lng=120.16 qual=1│
  │  上传成功                        │
  └─────────────────────────────────┘

  无GPS信号时:
  ┌─────────────────────────────────┐
  │  定位失败: 无法获取足够的卫星信号 │
  └─────────────────────────────────┘

【常见问题】

  Q: 板子显示"上传失败"
  A: 检查 .env 中的 MQTT_HOST 是否为PC的IP
     检查PC端是否已启动 mqtt\__main__.py
     检查Windows防火墙是否放行1883端口

  Q: 板子显示"定位失败"
  A: 检查K803接线是否正确 (VCC/GND/TXD)
     检查GPS天线是否在室外或窗边
     首次定位可能需要1-2分钟搜星

  Q: PC端 app.py 显示"No data collected"
  A: 表示MQTT桥接没有收到数据
     先确认板子main.py在运行
     再确认 mqtt\__main__.py 在运行

  Q: 汉字显示乱码
  A: PowerShell中执行: chcp 65001
     或使用 Windows Terminal 运行

六、MQTT Broker 安装与使用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【什么是MQTT Broker】
  MQTT Broker 是开发板和服务器之间的"中转站"。
  开发板把GPS数据发给Broker, 服务器从Broker接收。
  即使两边不在同一网络, 也能通过公网Broker中转。
  
  架构:
    树莓派 ──发布──→ MQTT Broker ──订阅──→ PC服务器
    (软件端)        (mosquitto/EMQX)     (bridge_service.py)

【方案A: 同一台PC上运行 (最简单)】

  适用场景: 开发板和PC在同一个局域网 (WiFi)

  Windows上安装mosquitto:
    # 方法1: winget (推荐)
    winget install mosquitto

    # 方法2: 手动下载安装
    # 1. 下载: https://mosquitto.org/download/
    # 2. 运行安装包, 勾选 "Service" 选项
    # 3. 安装完成后, 以管理员身份运行PowerShell:
    net start mosquitto

    # 验证是否启动成功:
    netstat -an | findstr "1883"
    # 应看到: TCP 0.0.0.0:1883 LISTENING

  配置开发板 .env:
    MQTT_HOST=你的PC的IP地址  (如 192.168.1.100)
    MQTT_PORT=1883
    MQTT_USER=                # 无加密, 留空
    MQTT_PASS=

  配置服务器端 mqtt/config.py:
    broker_host = "localhost"  # 或 "127.0.0.1"
    broker_port = 1883
    use_tls = False

【方案B: 使用公共EMQX Cloud (跨网络)]
  
  适用场景: 开发板用4G, PC在家里, 不在一起

  1. 注册: https://www.emqx.com/zh/cloud
  2. 创建免费部署 (30天/1G流量)
  3. 获取连接地址: broker.emqx.io:1883
  4. 配置开发板和服务器都填这个地址

【方案C: 树莓派上直接装mosquitto】

  适用场景: 不想占用PC, 树莓派当Broker

  在树莓派上:
    sudo apt update
    sudo apt install -y mosquitto mosquitto-clients

    # 启动服务:
    sudo systemctl enable mosquitto
    sudo systemctl start mosquitto

    # 检查状态:
    sudo systemctl status mosquitto

  配置开发板 .env:
    MQTT_HOST=localhost       # 板子自己就是Broker
    MQTT_PORT=1883

  配置PC服务器端 .env:
    MQTT_HOST=树莓派的IP
    MQTT_PORT=1883

【测试MQTT连接】

  发送端 (模拟开发板):
    mosquitto_pub -h localhost -t "survey/test" -m "hello" -q 1

  接收端 (模拟服务器):
    mosquitto_sub -h localhost -t "survey/test" -q 1
    # 收到 "hello" 说明Broker正常工作

  测试完整链路:
    # 终端1: 启动服务器桥接
    cd 服务器端
    python mqtt\__main__.py

    # 终端2: 测试发布
    mosquitto_pub -h localhost -t "survey/data/DEV-001" -m '{"device_id":"DEV-001","A":{"lat":30.25,"lng":120.16},"B":{"lat":30.25,"lng":120.16},"C":{"lat":30.25,"lng":120.16},"survey_time":1712345678}' -q 1

    # 终端3: 查看结果
    cd 服务器端
    python app.py
    # 选4 查看总库数据

【常见问题】
  Q: 启动mosquitto提示"address already in use"
  A: 可能已经启动了, 用 netstat -an | findstr 1883 检查
     或者任务管理器结束 mosquitto.exe 再重试

  Q: 开发板连不上Broker
  A: 确认 .env 中 MQTT_HOST 填的是PC的IP (不是 localhost)
     检查Windows防火墙是否放行1883端口:
     netsh advfirewall firewall add rule name="MQTT" dir=in action=allow protocol=TCP localport=1883

  Q: 服务器端 bridge 连不上Broker
  A: 确认 mqtt/config.py 中的 broker_host 设置正确
     如果用同一台PC, 填 localhost 或 127.0.0.1
