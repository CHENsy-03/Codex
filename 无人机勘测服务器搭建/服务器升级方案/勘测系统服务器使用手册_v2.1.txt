=====================================================================
  勘测系统服务器 V2.1 — 小白使用手册
=====================================================================

欢迎使用勘测系统服务器！本手册假设你没有任何编程基础。

=====================================================================
一、怎么安装
=====================================================================

1. 确保电脑有 Python (3.12 或更高版本)
   检查方法: 打开 PowerShell, 输入 python --version
   如果没有: https://python.org 下载安装 (勾选"Add to PATH")

2. 解压服务器代码包到任意位置, 例如: D:\勘测系统\

3. 安装必要的库 (只需运行一次):
   打开 PowerShell, 输入:

   cd D:\勘测系统\服务器端
   pip install duckdb protobuf pyyaml psutil pyserial

   等待安装完成即可。

=====================================================================

三、菜单怎么用
=====================================================================

主菜单有 9 个选项:

  1. 查看系统状态     → 看服务器基本信息、版本号、运行状态
  2. 数据查询与浏览   → 看数据、录入数据、导入文件 (最常用!)
  3. 协议解析测试     → 手动输入 GPS 报文测试解析
  4. 离线消息队列     → 看断网时缓存的消息
  5. 服务器注册管理   → 看已注册的分部服务器
  6. 系统设置         → 高级设置 (Gateway/API/WebSocket等)
  7. 系统健康检查     → 看 CPU/内存/磁盘
  8. 设备模拟器       → 批量注入模拟数据
  9. 数据管理         → 删除/清空数据
  0. 退出

操作方式: 输入数字 → 回车 → 看结果 → 再回车继续

=====================================================================
四、常见操作
=====================================================================

4.1 查看已存储的数据
  主菜单 → 输入 2 → 回车
  → 输入 1 → 回车 (浏览全部, 分页)
  → 输入 n 看下一页, p 看上一页, q 退出

4.2 查找某个设备的数据
  主菜单 → 2 → 2 → 输入设备ID → 回车

4.3 查看最近的数据
  主菜单 → 2 → 3 → 输入 10 → 回车 (看最近10条)

4.4 手动录入一次勘测
  主菜单 → 2 → 5
  → 选省份 (1=浙江 或 2=云南)
  → 选城市
  → 选区县 (输入名称)
  → 依次输入 A/B/C 三组数据, 每组输入6个数字:
     纬度 经度 高度(米) H精度(cm) V精度(cm) D精度(cm)
     示例: 30.25 120.16 50.0 3.2 2.8 4.1
  → 系统自动比较三组数据是否一致
  → 一致则输入 y 保存

4.5 从文件导入数据
  主菜单 → 2 → 7
  → 输入文件完整路径 (支持 .json / .csv / .txt)
  → 系统自动识别每条数据属于哪个地区
  → 显示导入结果

4.6 查看汇总统计
  主菜单 → 2 → 8
  → 显示总记录数、总批次数、按类型分布

4.7 启动 Web 接口 (方便外部程序访问)
  主菜单 → 6 → 12 → 回车 (启动 REST API)
  → 打开浏览器, 输入 http://127.0.0.1:8080/api/v1/
  → 看到登录页面就成功了
  → 用户名: admin  密码: admin123
  → 点登录 → 显示 Token → 点"测试API"查看返回数据

=====================================================================
五、怎么让 Java 程序连接服务器
=====================================================================

前提: 服务器已启动 + REST API 已启动 (第4.7步)

5.1 Java 代码示例 (复制粘贴即用)

创建一个 Java 文件 TestServer.java:
----------------------------------------------------
import com.uav.sdk.UavClient;

public class TestServer {
    public static void main(String[] args) throws Exception {
        // 1. 创建客户端, 指向你的服务器地址
        UavClient client = new UavClient("http://127.0.0.1:8080");

        // 2. 登录 (账号密码默认 admin/admin123)
        String loginResult = client.login("admin", "admin123");
        System.out.println("登录: " + loginResult);

        // 3. 创建勘测项目
        String project = client.createProject("测试项目", "杭州", "张三");
        System.out.println("项目: " + project);

        // 4. 注册设备
        String device = client.registerDevice("RTK001", "GNSS", "K803");
        System.out.println("设备: " + device);

        // 5. 查询设备状态
        String status = client.deviceStatus("RTK001");
        System.out.println("状态: " + status);
    }
}
----------------------------------------------------

5.2 编译和运行

  1. 把 server_sdk\java\src 目录下的 UavClient.java 复制到你的项目
  2. 编译:
     javac UavClient.java TestServer.java
  3. 运行:
     java TestServer
  4. 看到返回 JSON 数据就是成功了

5.3 如果你用 Maven:

  pom.xml 里加入 SDK 依赖:
  把 server_sdk\java\ 整个目录作为独立模块引入, mvn install

5.4 如果你开发 Android:

  UavClient.java 使用纯 JDK (HttpURLConnection), 可以直接复制到
  Android 项目, 注意把网络请求放到子线程 (AsyncTask / Coroutine)。

5.5 Java 可用的全部方法:

  client.login(user, pass)           登录
  client.createProject(name,loc,op)  创建项目
  client.getProject(pid)             查项目
  client.listProjects()              项目列表
  client.registerDevice(id,type,mdl) 注册设备
  client.deviceStatus(did)           设备状态
  client.deviceList()                设备列表
  client.startTask(did,pid,dur)      启动任务
  client.taskStatus(tid)             任务状态
  client.positionLatest(did)         最新坐标
  client.resultGet(pid)              勘测结果
  client.surveyUpload(pid,data)      上传数据

六、常见问题
=====================================================================

Q: 启动报错"端口被占用"?
A: 可能有另一个程序占用了 9000 端口。关闭后重试。
   检查: netstat -ano | findstr 9000

Q: 启动后菜单中文乱码?
A: PowerShell 默认编码问题。用 Windows Terminal 或 cmd 启动。

Q: 数据太多, 怎么清理?
A: 主菜单 → 9 → 2 → yes (清空全部GNSS数据)

Q: REST API 返回 "auth required"?
A: 需要先登录获取 Token。浏览器打开 http://127.0.0.1:8080/api/v1/
   点击登录按钮即可。

Q: Java 连接报错 "Connection refused"?
A: 检查服务器是否启动, REST API是否开启 (6→12)。

Q: 怎么修改密码?
A: 当前版本密码固定为 admin/admin123。修改需编辑
   api/auth_handler.py 中的 _users 字典。

Q: 数据库文件在哪里?
A: data/gnss_data.duckdb
   备份: data/backups/
   日志: data/server.log

Q: 怎么让其他人访问?
A: 默认监听 0.0.0.0:8080, 局域网内其他电脑用
   http://你的IP:8080/api/v1/ 即可访问。
