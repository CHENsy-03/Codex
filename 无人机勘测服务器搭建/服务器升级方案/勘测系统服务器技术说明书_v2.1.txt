  勘测系统服务器 V2.1 — 技术说明书
=====================================================================

一、系统概述
---------------------------------------------------------------------
勘测系统服务器是一款无人机/RTK GNSS 数据采集与管理的边缘计算平台。
支持多级部署（总服务器→省级→市级→县级），通过 4G/5G 公网接收设备
报文，解析 GPGGA/BESTPOS 定位数据，存入 DuckDB 数据库，通过 REST API
对外提供数据服务。

技术栈: Python 3.12+ / DuckDB / Protobuf / asyncio
通信: 自写 TCP Server + Frame 协议 + 自写 WebSocket (零外部 Web 框架)
存储: DuckDB 列式数据库 (6 张表)

二、系统架构
=====================================================================

  设备层 (RTK/GNSS/无人机)
       │
       │  4G/5G/WiFi TCP + Frame 协议 (CRC32)
       ▼
  ┌─────────────────────────────────┐
  │         Gateway 网关             │
  │  (asyncio TCP Server + Frame)   │
  └─────────────────────────────────┘
       │
       ▼
  ┌─────────────────────────────────┐
  │      Protocol Parser            │
  │  GPGGA (NMEA ASCII)             │
  │  BESTPOS (NovAtel Binary)       │
  │  → 统一 GNSSData 对象           │
  └─────────────────────────────────┘
       │
       ├──→ Session Manager (断线恢复)
       ├──→ ACK Manager (可靠性)
       ├──→ Resend (超时重传)
       │
       ▼
  ┌─────────────────────────────────┐
  │      DuckDB Storage             │
  │  6 表: gnss_position,            │
  │  device_session, offline_message,│
  │  server_registry, sync_log,      │
  │  ack_pending                     │
  └─────────────────────────────────┘
       │
       ├──→ Cluster Sync (protobuf)
       │    县级→市级→省级→总服务器
       │
       ├──→ REST API (HTTP/JSON)
       │    /api/v1/* + /api/stats/summary
       │
       └──→ WebSocket (实时推送)
            ws://host:8081/api/ws/device

三、模块结构

四、数据库表结构 (DuckDB)
=====================================================================

gnss_position (GNSS 定位数据):
  id BIGINT PK, device_id VARCHAR, msg_type VARCHAR, latitude DOUBLE,
  longitude DOUBLE, height DOUBLE, solution_type INT, diff_age DOUBLE,
  station_id VARCHAR, source_channel VARCHAR, raw_data BLOB,
  gnss_time BIGINT, e/n/u_accuracy DOUBLE, server_id VARCHAR, created_at BIGINT

device_session (设备会话):
  device_id VARCHAR, session_id VARCHAR, channel VARCHAR, last_seq INT,
  status VARCHAR, heartbeat_time BIGINT, created_at BIGINT

offline_message (离线消息):
  id BIGINT PK, device_id VARCHAR, sequence INT, payload BLOB,
  status VARCHAR, retry_count INT, created_at BIGINT

server_registry (服务器注册):
  server_id VARCHAR PK, server_name VARCHAR, level VARCHAR,
  host VARCHAR, port INT, status VARCHAR, last_seen BIGINT

sync_log (同步日志):
  id BIGINT PK, from_server VARCHAR, to_server VARCHAR,
  sync_type VARCHAR, records INT, status VARCHAR, created_at BIGINT

ack_pending (ACK待确认):  -- V2.1 新增, 服务器重启不丢数据
  device_id VARCHAR, sequence INT, session_id VARCHAR,
  payload BLOB, status VARCHAR, retry_count INT, created_at BIGINT

五、REST API 接口完整参考
=====================================================================

服务器: http://127.0.0.1:8080
统一返回格式: {"code":0,"message":"success","timestamp":...,"data":{...}}

公开端点 (无需登录):
GET  /api/v1/              登录页 (HTML)
POST /api/v1/auth/login    登录 {"username":"admin","password":"admin123"}
     → {"code":0,"data":{"token":"xxx","expire":7200}}
GET  /api/stats/summary    统计摘要 {"total_gnss":N,"by_type":{...},"tables":{...}}

认证端点 (需 Bearer Token):
POST /api/v1/project/create  创建项目
GET  /api/v1/project/list    项目列表
GET  /api/v1/project/{id}    项目详情
POST /api/v1/device/register 设备注册
GET  /api/v1/device/status/{id} 设备状态
GET  /api/v1/device/list     设备列表
POST /api/v1/task/start      启动任务
GET  /api/v1/task/status/{id} 任务状态
GET  /api/v1/position/latest/{id} 最新坐标
GET  /api/v1/result/{id}     勘测结果
POST /api/v1/survey/upload   上传勘测数据

六、Java SDK 使用指南
=====================================================================

文件位置: server_sdk\java\src\main\java\com\uav\sdk\

编译 (零外部依赖, 纯 JDK):
  cd server_sdk\java
  javac -d target src/main/java/com/uav/sdk/UavClient.java
  javac -cp target -d target src/main/java/com/uav/sdk/Example.java

Maven (可选):
  mvn compile

Java 调用示例:
----------------------------------------------------
import com.uav.sdk.UavClient;

public class MyApp {
    public static void main(String[] args) throws Exception {
        UavClient client = new UavClient("http://127.0.0.1:8080");

        // 1. 登录
        client.login("admin", "admin123");

        // 2. 创建项目
        String project = client.createProject("山区测量", "绍兴", "张三");
        System.out.println("项目: " + project);

        // 3. 注册设备
        String device = client.registerDevice("RTK001", "GNSS", "K803");
        System.out.println("设备: " + device);

        // 4. 查询设备状态
        String status = client.deviceStatus("RTK001");
        System.out.println("状态: " + status);

        // 5. 上传勘测数据
        String survey = client.surveyUpload("P001",
            "RTK001,30.5,120.2,50.0\nRTK001,30.51,120.21,50.5");
        System.out.println("上传: " + survey);
    }
}

=====================================================================
七、通信帧协议
=====================================================================

Frame 结构 (HEADER_SIZE = 52 bytes):
  Magic(2B) Version(1B) MsgType(1B) DeviceID(16B) SessionID(16B)
  Sequence(4B) PayloadLength(4B) Timestamp(8B)
  + Payload (变长)
  + CRC32 (4B)

消息类型:
  0x0001 Heartbeat  0x0002 GNSS      0x0003 IMU
  0x0004 Status     0x0005 File      0x0006 ACK
  0x0007 NACK       0x0008 Config    0x0009 Command

=====================================================================
八、WebSocket 协议
=====================================================================

连接: ws://127.0.0.1:8081/api/ws/device

客户端 → 服务器:
  {"type":"subscribe"}     订阅实时推送

服务器 → 客户端:
  {"type":"subscribed","status":"ok"}
  {"type":"position","device_id":"xxx","latitude":...,"longitude":...}

心跳: 服务器每 30s 发 Ping (opcode 0x9), 客户端自动回复 Pong (0xA)
超时: 90s 无 Pong → 主动断开

十、配置文件 server.yaml
=====================================================================

server:
  id: "SURVEY-SRV-001"       服务器编号
  name: "勘测系统服务器"      服务器名称
  level: "center"             层级 (county/city/province/center)
  host: "0.0.0.0"
  port: 9000                  设备通信端口

database:
  path: "data/gnss_data.duckdb"
  memory_limit: "4GB"         内存上限
  temp_directory: "data/temp" 溢出临时目录
  scanner_threshold_gb: 1.0   大文件直扫阈值

sync:
  upstream_id: ""             上级服务器ID (center级别为空)
  sync_interval: 60           同步间隔(秒)
  batch_size: 1000            批量同步条数

城市配置文件: config/cities/hangzhou.yaml, shaoxing.yaml 等
  启动: python app\server.py --config config/cities/hangzhou.yaml
