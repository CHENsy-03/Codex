- 结果可重复；
- 不使用真实密钥或账号。

测试结果必须来自实际执行。

## 16. 任务状态定义

| 状态 | 含义 |
|---|---|
| draft | 任务定义未完成 |
| ready | 定义完成，等待执行 |
| in_progress | 正在实施 |
| blocked | 遇到阻塞，等待开发者决定 |
| review | 实施完成，等待审查 |
| completed | 验收标准全部通过 |
| cancelled | 任务已取消 |

只有全部验收标准通过后才能标记为 `completed`。

不得通过弱化测试、跳过检查或虚构结果标记完成。
