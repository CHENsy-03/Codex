# DEVELOPMENT_CHECKLIST.md

> 本文件用于提醒开发者和 AI 在开发过程中不要遗漏关键步骤。
>
> 每完成一个任务，都应按以下顺序检查。

---

## 1. 开发前

- [ ] 阅读根目录 `AGENTS.md`；
- [ ] 阅读当前项目 `AGENTS.md`；
- [ ] 阅读项目架构、任务和开发规则；
- [ ] 检查当前分支、HEAD、暂存区、工作区和未跟踪文件；
- [ ] 确认允许修改和禁止修改的范围；
- [ ] 理解调用关系、数据流和现有测试；
- [ ] 记录修改前基线。

---

## 2. 修改中

- [ ] 只修改任务允许的文件；
- [ ] 不覆盖用户预存修改；
- [ ] 不引入无关重构；
- [ ] 不为简单功能引入大型依赖；
- [ ] 不在日志、结果和错误信息中输出秘密值；
- [ ] 不忽略错误；
- [ ] 不执行未经授权的 Git 写操作；
- [ ] 需要扩大范围时先停止并报告。

---

## 3. 测试与验证

- [ ] 为新增行为补充测试；
- [ ] 覆盖成功路径、失败路径和安全边界；
- [ ] 运行相关模块测试；
- [ ] 运行项目要求的静态检查；
- [ ] 运行项目全量测试；
- [ ] 记录真实命令、真实数量和真实退出码；
- [ ] 不跳过、不弱化既有测试。

---

## 4. 文档同步

- [ ] 公共接口变化已更新文档；
- [ ] 数据模型变化已更新文档；
- [ ] 配置变化已更新示例和说明；
- [ ] 任务状态已更新；
- [ ] 变更日志已记录；
- [ ] 根级文档不写入项目专属内容。

---

## 5. 提交前检查

- [ ] `git status` 已检查；
- [ ] `git diff --stat` 已检查；
- [ ] 完整 `git diff` 已检查；
- [ ] 没有无关修改；
- [ ] 没有敏感信息；
- [ ] 没有生成文件误入提交范围；
- [ ] 是否暂存和提交由开发者决定。

---

## 6. 阻塞检查

如果任务无法继续：

- [ ] 已明确阻塞原因；
- [ ] 已列出已完成修改；
- [ ] 已列出未完成修改；
- [ ] 已说明需要谁确认；
- [ ] 已说明需要什么信息；
- [ ] 未通过猜测绕过阻塞。

---

End.
