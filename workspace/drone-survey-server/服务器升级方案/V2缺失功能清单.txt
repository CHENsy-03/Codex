二、完全缺失的功能 (7项)
----------------------------------------------------------------

1. 手动录入勘测数据（A/B/C 三组）
   V1行为: 选择地区 → 输入三组不重复的坐标(纬度/经度/高度/H/V/D精度)
           → 三组互相比较 → 误差小于阈值则存入对应地区分库
   V2现状: 无此功能
   V1文件: app.py 内 _manual_input(), input_group()

2. 查看分部服务器数据 (三级层级浏览)
   V1行为: 一级(省) → 二级(市) → 三级(区县) → 分页浏览数据
           浙江 → 杭州/绍兴 → 各区县
           云南 → 昭通 → 永善/昭阳/鲁甸/镇雄/威信等
   V2现状: 只有平铺的"数据查询"，没有层级结构
   V1文件: app.py 内 _view_shard(), shard_db.py

3. 查看总部汇总统计
   V1行为: 显示总GPS记录数/总结果数/总勘测点数，按省份聚合显示
   V2现状: "数据查询"只能看原始记录，没有聚合统计
   V1文件: app.py 内 _view_summary()

4. 图表/Excel 数据文件导入 (主菜单入口)
   V1行为: 主菜单6 → 输入路径 → JSON/Excel/CSV/TXT文件导入
           → 自动识别地区(杭州/绍兴) → 逐条验证 → 存入分库
   V2现状: 只有CSV导出(在设置子菜单)，没有主菜单导入入口
   V1文件: app.py _import_data(), processor/*, upgrade/import_validator.py

5. 事件总线状态与回放 (EventBus)
   V1行为: 查看EventBus统计(total_events/history_size/topics)
           支持事件回放
   V2现状: 有 eventbus/ 文件但未集成到菜单
   V1文件: eventbus/core.py, eventbus/stream.py, eventbus/topic.py

6. 插件管理 (Plugin SDK + Sandbox)
   V1行为: 已注册插件列表、沙箱开关、插件测试处理
           支持 BESTPOS/CM510/K803/NMEA 插件
   V2现状: V1的 plugins/ 目录还在，但V2菜单完全不暴露
   V1文件: plugins/, upgrade/plugin_sdk.py, upgrade/sandbox.py

7. GPS 回放系统 (完整版)
   V1行为: 完整的 GPS 报文回放引擎(timeline/signal/file replay)
   V2现状: debug/packet_replay.py 功能更简单(仅文件→DB或文件→TCP)
   V1文件: replay/gps_replay.py, replay/timeline_engine.py, replay/signal_replay.py

三、部分覆盖但弱化的功能 (4项)
----------------------------------------------------------------

8. 模拟定位器自动录入 → V2改名为"设备模拟器"
   V1: 选择地区 → 三组定位值自动生成+比较 → 存入分库
   V2: 只选数量 → 批量注入 GPGGA/BESTPOS 到总库，无地区分配
   差距: 缺地区自动识别、三组比较、存入分库

9. 查看总部服务器数据 → V2合并到"数据查询与浏览"
   V1: 按省份选择 → 显示该省汇总+最近30条定位点
   V2: 分页浏览原始记录
   差距: 缺省份聚合、汇总数字

10. 命令行测试引擎 (CLI)
   V1: cli/main.py, cli/test_runner.py, cli/stream_view.py 等独立CLI
   V2: debug/目录有测试模块，但没有统一的CLI入口
   差距: 缺统一CLI框架

11. 系统升级功能 (统计API/熔断)
   V1: 主菜单9 → 子菜单含重复检测统计/熔断状态/统计API(端口8080)
   V2: maintenance/upgrade.py 只有版本迁移，没有统计API服务器
   差距: 缺重复检测/熔断状态界面、统计API独立端口服务
