=== 考试小程序 - 题库格式说明 =====================================================

一、成功上传的格式（共 3 种）
------------------------------------------------------------

格式 1：Word 文档（.docx）—— 单文件上传
  每道题按以下段落顺序编排（字母前缀 + 答案行）：
     1. 题目文字
     A. 选项一
     B. 选项二
     C. 选项三
     D. 选项四
     答案：A
  解析后自动识别选项与答案，是最推荐的方式。
  支持分隔符：题号用 "1." "1、" "1)"；选项用 "A." "A)" "A、"；答案用 "答案：A" "正确答案：A"
  >> 已为你生成：超视距飞行基础知识题库_已转换.docx（297道题，可直接上传）

格式 2：Word 文档（.docx）+ 单独答案文件（.txt）
  文档中每道题只需写出题目和选项（可省略答案行），另配一个答案文件。
  答案文件格式（每行一个）：
     1:A
     2:B
     3:C
  >> 已为你生成：答案文件.txt（与上述 .docx 配套使用）

格式 3：答案文件单独覆盖（.txt）
  如果有现成的 .docx 题库但答案不正确，可以上传一个独立的答案文件覆盖。
  格式同上（题号:答案字母）。

二、不支持的格式
------------------------------------------------------------
  x 纯文本 .txt 题库（未配答案文件）—— 小程序只解析 .docx
  x 选项前没有 A./B./C./D. 前缀的文档 —— 无法识别选项边界
  x 没有答案行也没有配套答案文件的文档
  x PDF、图片等其他格式

三、5 题示例（标准格式）
------------------------------------------------------------
  1. 下面哪个是 Python 中的可变数据类型？
  A. tuple
  B. str
  C. list
  D. int
  答案：C

  2. 在 Python 中，用于定义函数的保留字是哪个？
  A. function
  B. def
  C. define
  D. func
  答案：B

  3. 执行 print(2 ** 3) 的输出结果是？
  A. 5
  B. 6
  C. 8
  D. 9
  答案：C

  4. Python 中，以下哪个方法用于向列表末尾添加元素？
  A. insert()
  B. append()
  C. add()
  D. push()
  答案：B

  5. 表达式 "Hello, World!"[7:12] 的结果是？
  A. World
  B. World!
  C. ello,
  D. o, Wo
  答案：A
