## 2. 独立 oracle 方法

测试侧不调用生产计算函数生成期望值，独立计算：

1. 仿射基准：使用测试构造时已知的 Affine，独立计算 pixel ↔ map_crs；
2. CRS 基准：独立建立 `pyproj.Transformer.from_crs(<map crs>, "EPSG:4326", always_xy=True)`；
3. 距离基准：测试侧独立 `pyproj.Geod(ellps="WGS84").inv`；
4. 时间基准：测试侧独立 `distance/speed` + `math.ceil` + `divmod`。

每个用例比较三条链：独立数学基准 / WorkerEngine 直接结果 / NDJSON 公共协议结果；条件允许时增加第四条既有领域函数链。
