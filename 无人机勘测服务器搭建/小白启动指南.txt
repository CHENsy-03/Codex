📌 本指南写给"没用过Python、不懂命令行"的人看。
  每一步都告诉你：① 在哪里操作  ② 输入什么  ③ 会看到什么


──────────────────────────────────────────────
第一步：打开服务器
──────────────────────────────────────────────

操作位置：在 PowerShell 或 CMD（命令提示符）里输入

【如果你在 PowerShell 里】
先输入下面这行，按回车：
  cd "E:\AI_Projects\Codex\无人机勘测服务器搭建\服务器端"

再输入下面这行，按回车：
  python app.py

屏幕会显示：
  =======================================================
    勘测系统服务器 v0.1.1 — V4-Local 工业级测试引擎
  =======================================================
  
  请选择操作：
    1. 手动录入勘测数据（A/B/C 三组）
    2. 模拟定位器自动录入
    3. 查看分部服务器数据
    4. 查看总部服务器数据
    ...（后面的选项）...
    0. 退出

看到这个菜单，就说明服务器启动成功了！🎉


──────────────────────────────────────────────
第二步：试试最简单的功能（模拟数据）
──────────────────────────────────────────────

在刚才的菜单里：

① 输入数字 2，按回车
   → 屏幕显示"可用地区："
   → 输入 1，按回车（选杭州）

② 输入要模拟几轮，比如 3，按回车
   → 服务器会自动生成 3 轮假数据
   → 每轮包含 A/B/C 三组定位记录
   → 每轮会告诉你"成功"还是"失败"
   → 成功的数据自动存入数据库

③ 查看存了什么
   回到菜单，输入 3，按回车
   → 选 1（杭州）
   → 就能看到刚才存进去的数据了


──────────────────────────────────────────────
第三步：查看结果
──────────────────────────────────────────────

回到菜单，输入 5，按回车
  → 显示总部统计：共有多少条数据、正确几条、错误几条

或者（另开一个 PowerShell 窗口）：
  python -m cli.result_query --all
  → 显示所有设备的结果
  → 1=正确  0=错误  -1=未知


──────────────────────────────────────────────
第四步：退出
──────────────────────────────────────────────

在菜单输入 0，按回车


──────────────────────────────────────────────
常见问题
──────────────────────────────────────────────

Q: 输入 cd 后提示"找不到路径"
A: 说明你当前不在 E:\AI_Projects\Codex 目录下。
   先输入： E:
   再输入： cd E:\AI_Projects\Codex
   然后再按上面的步骤操作。

Q: 输入 python app.py 提示"python 不是内部或外部命令"
A: 说明 Python 没装好。先安装 Python 3.12 或更高版本。

Q: 输入 python app.py 后报错 ModuleNotFoundError
A: 缺少依赖库。先输入：
   pip install duckdb paho-mqtt fastapi uvicorn websockets aiofiles

Q: 看不到中文，全是乱码
A: 在 PowerShell 里先输入：
   chcp 65001
   按回车，再重新运行 python app.py

本指南写给第一次接触这个项目的人。从拿到ZIP到成功运行的完整步骤。

──────────────────────────────────────────────
第一步：安装 Python
──────────────────────────────────────────────
1. 打开 https://www.python.org/downloads/ 下载 Python 3.12+
2. 安装时勾选 "Add Python to PATH"
3. 打开命令提示符(CMD)或PowerShell，输入：python --version
4. 确认显示 Python 3.12.x

──────────────────────────────────────────────
第二步：安装依赖库
──────────────────────────────────────────────
1. 解压ZIP到一个文件夹
2. 打开 PowerShell，进入该文件夹
3. 输入以下命令安装依赖：

   pip install -r requirements.txt

   如果下载慢，加国内镜像：
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

──────────────────────────────────────────────
第三步：启动服务器
──────────────────────────────────────────────
在 PowerShell 输入：

   cd 服务器端
   python app.py

看到菜单就说明成功了！

──────────────────────────────────────────────
第四步：测试功能
──────────────────────────────────────────────
输入 2，回车 → 选地区 1(杭州) → 输入模拟轮数 3
  自动生成A/B/C三组数据，自动比对存储
输入 3，回车 → 选地区 1(杭州)
  查看刚才存的数据
输入 5，回车 → 查看总部汇总统计
输入 0，回车 → 退出

──────────────────────────────────────────────
常见问题
──────────────────────────────────────────────
Q: "python" 不是内部或外部命令
A: 重新安装Python，勾选 "Add Python to PATH"

Q: pip install 报错
A: 用国内镜像：pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

Q: ModuleNotFoundError
A: 依赖没装全。重试 pip install -r requirements.txt

Q: 中文显示乱码
A: 先输入 chcp 65001，回车，再运行 python app.py
