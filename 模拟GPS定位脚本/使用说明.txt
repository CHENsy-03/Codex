模拟GPS定位脚本 - 小白使用说明
===================================


【这是做什么的？】

这个脚本能模拟一台 GPS 接收机，不断输出定位报文。
你可以用它生成的报文来测试自己的 GPS 解析程序、
调试 TCP 服务器，或者给其他系统提供模拟 GPS 数据。


【文件说明】

  gps_simulator.py         主程序，运行这个就行
  config.py                配置文件，一般不用动
  sender.py                TCP发送模块，用TCP功能时自动调用
  使用说明.txt             就是你正在看的这个
  随机生成（不重复）.txt    模式1生成的报文（绍兴+杭州交替）
  SX随机生成.txt           模式2生成的报文（仅绍兴）
  HZ随机生成.txt           模式3生成的报文（仅杭州）
  运行结果.txt             每次运行的摘要结果（自动追加）


【怎么运行？】

第一步：打开命令行
  按住 Win + R，输入 cmd 回车。

第二步：定位到脚本目录
  cd /d E:\AI_Projects\Codex\模拟GPS定位脚本

第三步：直接运行（最简单的）
  python gps_simulator.py

这样会每秒输出 1 条 GPGGA 报文到屏幕上，按 Ctrl+C 停止。


【常用操作】


1. 只想要 GPGGA 报文（NMEA 格式）

  命令：python gps_simulator.py --type GPGGA

  输出示例：
  ,031458.50,2936.0122038,N,12030.3367855,E,1,11,7.9,39.0656,M,10.306,M,,*6A


2. 只想要 BESTPOS 报文（NovAtel 格式）

  命令：python gps_simulator.py --type BESTPOS

  输出示例：
  #BESTPOSA,COM3,0,60.0,FINESTEERING,2425,11717.500,...*b4e9bf03


3. 两种报文都要

  命令：python gps_simulator.py --type BOTH


4. 调整输出速度

  --rate 后面跟的数字表示每秒输出多少条报文：

  python gps_simulator.py --rate 10       每秒10条
  python gps_simulator.py --rate 100      每秒100条（快速压测）


5. 指定输出数量

  默认是持续发送，用 --count 限制条数：

  python gps_simulator.py --count 50      发50条就自动停


6. 保存到文件

  python gps_simulator.py --count 1000 --output mydata.txt

  生成的 1000 条报文会保存在 mydata.txt 里。


7. 换一组坐标（公司区）

  脚本内置了两组坐标：
    dormitory（默认）：宿舍区，海拔约40米
    company：公司区，海拔约150米

  命令：python gps_simulator.py --preset company


8. 通过 TCP 发送到其他程序

  如果你的另一个程序在监听端口（比如 9001），可以这样发过去：

  python gps_simulator.py --rate 5 --type BOTH --tcp-host 127.0.0.1 --tcp-port 9001


9. 交互式菜单（城市测量模式）

  运行后会出现菜单，让你选择测量方式：

  python gps_simulator.py --menu

  菜单选项：
    1. 随机生成（不重复）- 绍兴/杭州随机切换，每点3次
    2. 绍兴随机生成
    3. 杭州随机生成
    q. 退出

  或者也可以直接指定模式，跳过菜单：

  python gps_simulator.py --mode 1      # 随机不重复
  python gps_simulator.py --mode 2      # 绍兴
  python gps_simulator.py --mode 3      # 杭州


【城市测量模式说明】

这个功能可以让你在 绍兴 和 杭州 两个城市范围内，
随机生成测量点位，每个点位采集3次 GPS 报文。

模式1（随机不重复）：绍兴和杭州随机切换，每个点测3次，
  然后换到另一个城市的另一个点，保证不重复。
  保存到：随机生成（不重复）.txt

模式2（绍兴随机生成）：只在绍兴范围内随机取点。
  保存到：SX随机生成.txt

模式3（杭州随机生成）：只在杭州范围内随机取点。
  保存到：HZ随机生成.txt

运行后会在屏幕上显示每个点来自哪个城市。
打开生成的 txt 文件可以看到类似这样的内容：

  [杭州 点1] ,080000.00,3016.2626508,N,12008.7607202,E,...
  [杭州 点1] ,080001.00,3016.2627277,N,12008.7605206,E,...
  [杭州 点1] ,080002.00,3016.2626489,N,12008.7606937,E,...
  [绍兴 点2] ,080003.00,3000.1612345,N,12034.8712345,E,...

方括号里标记了城市和点位编号，同一个点位有3条报文。


【完整参数一览】

  参数            简写   说明                  默认值
  --rate          -r     每秒输出多少条         1.0
  --type          -t     报文类型               GPGGA
                          可选：GPGGA / BESTPOS / BOTH
  --preset        -p     坐标预设               dormitory
                          可选：dormitory / company
  --count         -c     总共发多少条            0（一直发）
  --output        -o     保存到哪个文件          不保存
  --tcp-host              TCP 目标地址           不使用TCP
  --tcp-port              TCP 目标端口           9001
  --lat                   自定义纬度（度）       用预设值
  --lon                   自定义经度（度）       用预设值
  --alt                   自定义海拔（米）       用预设值
  --noise                 位置噪声大小（度）     0.000005
  --sv-min                最少卫星数             8
  --sv-max                最多卫星数             16
  --mode         整数    城市测量模式           不启用
                          1=随机不重复(绍兴+杭州)
                          2=绍兴随机生成
                          3=杭州随机生成
  --menu                  交互式菜单模式         不启用
  --debug                 显示详细日志           关闭


【常见问题】

Q: 提示 'python' 不是内部或外部命令
A: 电脑没装 Python。去 python.org 下载安装，
   安装时记得勾选"Add Python to PATH"。

Q: 提示 No module named xxx
A: 这个脚本只用 Python 自带的库，不需要安装任何额外包。
   如果报错，可能是 Python 安装不完整，重装即可。

Q: 怎么停止运行？
A: 按 Ctrl+C。

Q: 屏幕上的中文是乱码
A: Windows 命令行对中文支持不好，这不影响报文数据本身。
   如果要用记事本打开这个文件看说明，右键点这个文件，
   选"打开方式 -> 记事本"就行。

Q: 生成的报文看不懂？
A: GPGGA 是标准的 GPS 定位报文格式（NMEA 0183），
   BESTPOS 是 NovAtel 品牌接收机的专有格式。
   如果你只需要位置数据，关注经纬度和海拔字段即可。

Q: 菜单模式选完后怎么操作？
A: 输入 1、2、3 或 q 然后回车就行。接着会让你输入
   测量点数（默认10个点，每个点测3次，共30条报文），
   直接回车用默认值，或者输入一个数字再回车。

Q: 每次运行结果保存在哪里？
A: 脚本同级目录下的 运行结果.txt 里，每次追加。
   用记事本打开就能看到每次运行的摘要。

Q: 点数和报文数是什么关系？
A: 每个测量点采集3次。如果你设了10个点，总共就会生成
   10 x 3 = 30 条报文。点数越多，覆盖范围越广。
