一、这是什么软件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

考试系统是一个在 Windows 电脑上离线运行的考试软件。

功能：
  · 无需联网，安装后即可使用
  · 支持导入 Word 格式的题库，自动识别题目和答案
  · 逐题作答，支持上一题/下一题
  · 提交后即时出分，显示每题正误
  · 系统崩溃后重新打开，已答题目自动恢复

适用场景：
  · 企业内部培训考试
  · 学校课堂测验
  · 无人机、航空等专业资格考前练习

二、电脑需要什么配置
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

系统要求：
  · Windows 10 或 Windows 11（64位）
  · 内存：2GB 以上
  · 硬盘：200MB 以上可用空间
  · 屏幕：分辨率 1024×768 以上

不需要：
  ❌ 不需要安装 Python
  ❌ 不需要安装 Go
  ❌ 不需要联网
  ❌ 不需要安装任何额外软件

三、我怎么发给别人（发布方式）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方式一：安装包（推荐——给普通用户）

  文件：
    考试系统安装包.exe

  发给用户后：
    用户双击 → 选择安装目录（默认 C:\Program Files\考试系统）
    → 自动安装 → 桌面出现「考试系统」图标
    → 双击图标，直接考试

  优点：
    · 一个文件，双击搞定
    · 自动创建桌面快捷方式和开始菜单
    · 用户不需要懂任何技术

方式二：免安装版（给懂电脑的人）

  文件夹：
    ExamSystem\release\     ← 把这个文件夹整个发过去

  发给用户后：
    用户解压 → 双击 考试系统.exe → 直接开始考

  优点：
    · 不用安装
    · 放在 U 盘里即插即用
    · 复制到任意位置都能运行

  缺什么：
    · 没有桌面快捷方式
    · 用户需要自己找到 .exe 文件

四、最终用户：如何安装和考试
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【第一步】安装

  如果你是安装包方式：
    1. 双击「考试系统安装包.exe」
    2. 点击「下一步」，选择安装目录（默认即可）
    3. 安装完成，桌面出现「考试系统」图标

  如果你是免安装方式：
    1. 把「release」文件夹解压到任意位置
    2. 双击里面的「考试系统.exe」

【第二步】开始考试（有内置题库）

  启动程序后，会自动加载内置题库。
  右下角会显示「已自动加载题库: 297 道题」。
  直接点击「开始考试」按钮即可。

【第三步】答题

  1. 每页显示一道题，点击对应的答案选项
  2. 点击「下一题」继续
  3. 可以随时点「上一题」返回修改
  4. 底部显示「未答 X 题」
  5. 所有题答完后，按钮变为「提交试卷」

【第四步】提交

  1. 点击「提交试卷」
  2. 如果有未答的题，系统会询问是否确定提交
  3. 确认后立即显示成绩

【第五步】查看成绩

  · 总分和得分率
  · 每题对错明细
  · 你的答案 vs 正确答案
  · 成绩页支持翻页（每页 10 题）
  · 点击「重新考试」再来一次
  · 点击「返回首页」换题库

【导入自己的题库】

  如果你想用自己的试卷而非内置题库：

  1. 在首页不要点「开始考试」，而是：
       点击「浏览...」选择你的 Word 文档（.docx）
       设置每题分值（默认1分）
       点击「解析题库」
       下方表格显示所有题目
  2. 确认无误后，点击「开始考试」

五、题库管理者：如何更换试卷
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如果你想换掉内置的试卷，把新的题库打包进安装包：

【第一步】准备好你的 Word 题库文件

  确保 Word 文件格式正确（见第六节「题库格式要求」）。

【第二步】将 Word 转换为 JSON

  打开命令提示符（CMD），执行：

    cd E:\AI_Projects\Codex\考试系统（python+go）
    python ExamSystem\client\parser.py 你的题库.docx ExamSystem\release\data\questions\default.json

  运行后，release\data\questions\default.json 就是新的试卷。

【第三步】重新编译安装包

    "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" ExamSystem\setup.iss

  生成的「考试系统安装包.exe」已经包含你的新试卷。
  把这个文件发给人，对方装好就能直接考试。

【如果有多套试卷】

  你想让不同人考不同试卷，可以准备多个 .json 文件：

    release\data\questions\
    ├── default.json          ← 默认试卷（自动加载）
    ├── 低空经济.json         ← 后续可切换（需要代码支持）
    └── 航空法规.json

  用户安装后程序会自动加载 default.json。上传其他试卷需要在
  首页通过「浏览...」选择对应的 Word 文档导入。

【安装后考试流程（无脑化）】

  用户双击考试系统.exe → 自动加载 297 题
  → 点击「开始考试」→ 答题 → 提交 → 看成绩
  （全程不需要操作文件，不需要导入任何东西）

六、题库格式要求（重要）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

你的 Word 文档每一道题必须按以下格式编排：

  1. 下面哪个是 Python 的关键字？
  A. class
  B. def
  C. if
  D. for
  答案：D

规则：
  · 题号以「数字」开头，后跟 . 、、) ） 均可（如 1. 1、 1) 1））
  · 选项以 A. B. C. D. 开头（也支持 A) A、等格式）
  · 答案行必须包含「答案」二字，后跟大写字母（A/B/C/D）
  · 两道题之间用空行隔开
  · 支持「正确答案：」「【答案】」等写法

支持 297 题甚至更多，没有问题。

七、常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 提示「无法启动后端服务」
A: 可能原因及解决方法：
    1. 杀毒软件拦截 → 关闭杀毒软件后重新运行
    2. 端口 8080 被占用 → 重启电脑
    3. 如果反复出现 → 重新安装一次

Q: 导入 Word 后没有题目
A: 可能是格式问题：
    1. 检查每道题是否有题号、选项、答案行
    2. Word 文档必须是 .docx 格式（不是 .doc）
    3. 如果 Word 里有表格，先把表格转成普通文字

Q: 考试中途程序卡住或崩溃
A: 不要怕，你的答题记录会自动保存。
    关闭程序重新打开，点击「开始考试」，之前答过的题会恢复。
    如果恢复失败，检查 release\data\sessions\ 目录是否有文件。

Q: 如何卸载？
A: 直接删除安装目录即可。
    默认位置：C:\Program Files\考试系统
    同时删除桌面快捷方式和开始菜单里的「考试系统」文件夹。

Q: 我换了题库，但重新打开还是旧题
A: 因为服务器缓存了旧题。重启一次考试系统即可。
    如果还不行，删除 release\data\sessions\ 下所有文件再重启。

Q: 可以多人同时用吗？
A: 目前是单机版。每人装一份即可。

Q: 兼容 Windows 7 吗？
A: 理论上可以，但未充分测试，建议使用 Windows 10/11。

八、高级：重新打包整个安装包
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如果你需要修改代码后重新生成安装包，完整步骤如下：

【步骤 1】编译 Go 后端

  cd ExamSystem\server
  go build -ldflags="-s -w" -o ..\release\backend\ExamSystem.exe .\cmd\server\

  生成：release\backend\ExamSystem.exe（6.7 MB）

【步骤 2】打包 Python 前端

  cd ..
  pyinstaller --onefile --windowed --name 考试系统 ExamSystem\client\main.py

  生成：dist\考试系统.exe（17.6 MB）→ 复制到 release\考试系统.exe

【步骤 3】编译安装包

  "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" ExamSystem\setup.iss

  生成：考试系统安装包.exe（21.3 MB）

【快速打包（一键脚本）】

  ExamSystem\tools\build_all.bat

  自动执行以上三个步骤。

【项目文件说明】

  ExamSystem\client\               ← Python 前端源码
  ExamSystem\server\               ← Go 后端源码
  ExamSystem\release\              ← 发布包
  ExamSystem\config\config.yaml    ← 配置文件
  ExamSystem\tools\                ← 工具脚本
  全部代码.txt                     ← 所有源码汇总（31个文件）
  考试系统安装包.exe               ← 分发给用户的安装程序

【注意事项】

  · 修改 config.yaml 中的 exam.show_answer_after_submit 可以
    控制交卷后是否显示正确答案（false=不显示，true=显示）
  · 修改 config.yaml 中的 server.token 可以更换API密钥
    修改后需要同步修改 client.py 中的默认 token
  · 考试记录存储在 release\data\sessions\ 目录
